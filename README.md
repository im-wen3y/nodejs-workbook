# Node.js 학습지

JavaScript 사용 경험자를 위한 실습 중심 Node.js 학습지입니다. 문법 복습 없이 실행 환경, 모듈, 파일, HTTP 서버를 차례로 다룹니다.

## 보기

`index.html`을 브라우저에서 열면 됩니다. 별도 빌드나 패키지 설치는 필요하지 않습니다.

## GitHub Pages로 공개하기

나중에 공개하려면 저장소의 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 선택하고, `main` 브랜치의 `/(root)`를 지정하세요. 이 저장소의 `index.html`이 첫 화면이 됩니다.
