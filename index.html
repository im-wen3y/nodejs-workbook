먼저 실행해 보기

Node.js는 브라우저 밖에서 JavaScript를 실행합니다. 아래 명령을 터미널에 입력하고 버전이 출력되는지 확인하세요.

node --version

mkdir node-memo && cd node-memo

학습 방법
각 코드 조각을 직접 입력하고 결과를 예측해 보세요. 체크박스는 이 브라우저에 저장되며, 다른 기기와 동기화되지 않습니다.

01 / RUNTIME

Node.js는 무엇을 제공할까?

브라우저의 window와 document 대신, Node.js에서는 실행 중인 프로세스와 운영체제 기능에 접근합니다. 가장 먼저 명령줄 인수를 읽어 봅시다.

hello.mjs
const name = process.argv[2] ?? '친구';
console.log(`안녕하세요, ${name}!`);
node hello.mjs 누리
# 안녕하세요, 누리!

process.argv의 앞 두 항목은 실행 파일과 스크립트 경로입니다. 직접 입력한 첫 인수는 인덱스 2에 있습니다. .mjs는 이 파일을 ECMAScript 모듈로 실행하겠다는 뜻입니다.

생각해 보기

브라우저 코드의 document.querySelector()를 이 파일에 넣으면 왜 동작하지 않을까요?

힌트 보기
Node.js 자체에는 브라우저의 문서 객체 모델(DOM)이 없습니다. 같은 JavaScript여도 실행 환경이 제공하는 API가 다릅니다.
02 / MODULES

파일을 나누고 명령을 등록하기

프로젝트 정보를 package.json에 기록하고, Node.js 내장 모듈을 가져오는 방법을 익힙니다. 처음에는 외부 라이브러리가 필요하지 않습니다.

npm init -y
npm pkg set type=module
npm pkg set scripts.start="node memo.js"
memo.js
import { argv } from 'node:process';

const [command, ...words] = argv.slice(2);

if (command === 'add') {
  console.log('추가할 메모:', words.join(' '));
} else if (command === 'list') {
  console.log('메모 목록을 보여줄 차례입니다.');
} else {
  console.log('사용법: npm start -- add 메모 내용');
}
npm start -- add Node.js 시작하기
npm start -- list

node:process는 Node.js 내장 모듈입니다. npm start -- 뒤의 값은 스크립트로 전달됩니다.

03 / FILE SYSTEM

메모를 파일에 저장하기

프로그램을 다시 실행해도 데이터가 남도록 파일을 사용합니다. 파일 작업은 node:fs/promises로 처리하고, 기다리는 동안에는 await를 사용합니다.

memo.js · 전체 코드로 교체
import { argv } from 'node:process';
import { readFile, writeFile } from 'node:fs/promises';

const file = new URL('./memos.json', import.meta.url);
const [command, ...words] = argv.slice(2);

async function readMemos() {
  try {
    return JSON.parse(await readFile(file, 'utf8'));
  } catch (error) {
    if (error.code === 'ENOENT') return [];
    throw error;
  }
}

const memos = await readMemos();

if (command === 'add') {
  const text = words.join(' ').trim();
  if (!text) throw new Error('메모 내용을 입력하세요.');
  memos.push({ id: Date.now(), text });
  await writeFile(file, JSON.stringify(memos, null, 2));
  console.log('저장했습니다.');
} else if (command === 'list') {
  memos.forEach(({ id, text }) => console.log(`${id}: ${text}`));
} else {
  console.log('사용법: npm start -- add 메모 내용 | list');
}

파일이 없는 첫 실행만 빈 목록으로 처리합니다. 권한 문제나 잘못된 JSON까지 빈 목록으로 바꾸면 실제 오류를 놓치므로 그대로 드러나게 둡니다.

생각해 보기

readFile()의 결과를 기다리지 않고 바로 JSON.parse()에 전달하면 어떤 값이 들어갈까요?

힌트 보기
readFile()은 파일 내용이 아니라 Promise를 즉시 반환합니다. 파일 내용을 사용하려면 await로 완료를 기다려야 합니다.
04 / HTTP

같은 메모를 API로 제공하기

이번에는 명령줄 인수 대신 HTTP 요청을 입력으로 받습니다. URL과 메서드에 따라 응답을 다르게 보내 봅시다.

server.js
import { createServer } from 'node:http';
import { readFile } from 'node:fs/promises';

const file = new URL('./memos.json', import.meta.url);

const server = createServer(async (request, response) => {
  response.setHeader('Content-Type', 'application/json; charset=utf-8');

  if (request.method === 'GET' && request.url === '/memos') {
    try {
      const data = await readFile(file, 'utf8');
      response.end(data);
    } catch (error) {
      if (error.code === 'ENOENT') {
        response.end('[]');
      } else {
        response.statusCode = 500;
        response.end(JSON.stringify({ error: '파일을 읽지 못했습니다.' }));
      }
    }
    return;
  }

  response.statusCode = 404;
  response.end(JSON.stringify({ error: '경로를 찾을 수 없습니다.' }));
});

server.listen(3000, () => {
  console.log('http://localhost:3000/memos');
});
node server.js
# 다른 터미널에서 실행
curl http://localhost:3000/memos
curl -i http://localhost:3000/없는-경로

서버는 실행 후 종료되지 않고 요청을 기다립니다. 멈추려면 서버를 실행한 터미널에서 Ctrl+C를 누르세요.

05 / NEXT STEP

여기까지 했다면

이제 Node.js의 기본 흐름을 경험했습니다. 다음 과제는 POST /memos를 직접 구현하는 것입니다. 요청 본문을 읽고, 입력을 검증하고, 저장한 뒤 201 상태로 응답해 보세요.

스스로 설명할 수 있나요?
